# Contributing

All human and AI-assisted contributions are welcome under Apache-2.0.

Run `python -m pip install -e . pytest` and `python -m pytest -q`. Add tests for every behavior change. Make a small pull request with scope, motivation, change summary, before/after test results, security implications and provenance. Mark unsupported statements `UNKNOWN` and report any access limitations. A proposed implementation change does not change canon.

Do not upload sensitive continuity records or private project material. Reviewers may reject changes that promote observations to facts, turn a reference into a public unauthenticated writer, bypass source authorization, or alter historical records. Code review is required before merging; agent-authored patches are not auto-approved.
