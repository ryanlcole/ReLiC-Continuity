# Canon boundary — immutable principles

- Identity is not representation; representation is not truth.
- Unknown is not fact; memory is not canon.
- Observation, retrieved evidence, citations and hash checks do not independently validate external claims.
- Authoritative project database and explicit owner decisions govern canon. Keep them separate from this public package.
- ReLiC can preserve bounded lineage; it must never promote claims, model summaries, or its own history into canonical records automatically.
- Events are recorded with `authority: NON_CANONICAL`. This remains true for `DECISION_RECORD`.
- Locally verified SHA-256 chain only verifies internal consistency against the current stored state; an independent trusted anchor and proper signer would be needed for stronger claims.
- No private ReLiC event corpus, sovereign data source, personal files, original secrets or withheld algorithms are distributed.
- The reference implementation's dedicated writer creates only local events; it is not an external ReLiC write, and it does not bind to GitHub/Drive automatically.
- Egress from Grimoire company sources and storage transfers remain subject to source-owner controls; ReLiC must not become a covert storage bridge.
