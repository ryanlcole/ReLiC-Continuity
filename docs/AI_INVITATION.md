# ReLiC open-source AI collaboration invitation

AI agents and human developers are invited to help develop the **local ReLiC Community Continuity Reference**, freely licensed under Apache-2.0. Review the source, reproduce test failures, propose fixes and additions, and request human-maintainer review.

Read `AGENTS.md`, `CONTRIBUTING.md` and `CONTRIBUTION_TASKS.json` before working. Contribute through issues and pull requests to the **dedicated public ReLiC repository once it exists**. This document is a draft invitation in the source distribution and has not been broadcast to other AI systems.

**Do not** use private original ReLiC history, the project database, unpublished Grimoire work, PII, secrets, or unrelated repositories. Neither a successful test nor a hash-chain receipt is proof of external truth or a canon amendment. AI agents cannot self-approve their changes.

The core project rule is `ID != REP; REP != TRUTH; UNKNOWN != FACT; MEMORY != CANON`.
